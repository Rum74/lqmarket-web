# ⚔️ LQMarket - Sàn Giao Dịch Tài Khoản Liên Quân Mobile Uy Tín

Hệ thống sàn thương mại điện tử chuyên biệt cho cộng đồng game thủ Liên Quân Mobile, hỗ trợ giao dịch trung gian Escrow tự động, bảo vệ quyền lợi người mua và người bán 100%.

## ✨ Tính Năng Nổi Bật
- 🛡️ **Bảo hiểm Escrow 100%**: Giữ tiền an toàn, chỉ thanh toán cho người bán sau khi người mua kiểm tra tài khoản thành công.
- ⚡ **Bàn giao tự động 24/7**: Cung cấp tài khoản và mật khẩu tức thì trong 5 giây sau khi thanh toán.
- 💳 **Ví điện tử LQMarket Pay**: Tích hợp thanh toán quét mã VietQR ngân hàng tự động, nạp/rút siêu tốc.
- 🔍 **Bộ lọc thông minh**: Tìm kiếm tài khoản theo Bậc Rank, số lượng Tướng, Trang phục hiếm (SSS, Thứ Nguyên Vệ Thần, Tuyệt Sắc...).
- 📊 **Bảng điều khiển quản trị (Admin Dashboard)**: Duyệt tin bán, xử lý khiếu nại tranh chấp, quản lý rút tiền và phân quyền người dùng.

## 🛠️ Công Nghệ Sử Dụng
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Database & Storage**: Google Cloud Firestore, Firebase Authentication
- **Deployment**: Vercel / Cloud Run
